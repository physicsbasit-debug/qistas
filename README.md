# قِسطاس

تطبيق عربي RTL خفيف لتوزيع أنصبة المعلمين والشعب.

**أنصبة موزونة، توزيع أذكى.**

## الإصدار 1.2.0: إعداد موحّد وخطة معزولة لكل مادة أو قسم

- دمج بيانات المدرسة، نطاق الصفوف، المادة أو القسم، عدد المعلمين، الشعب والحصص داخل خطوة واحدة منظمة.
- اختيار نوع الخطة:
  - مادة واحدة، مثل اللغة العربية أو الرياضيات أو الفيزياء.
  - قسم متعدد المواد، مثل العلوم أو الدراسات الاجتماعية.
- منع دخول أي مادة من خارج نطاق الخطة إلى المعلمين أو التوزيع أو Excel أو تقرير PDF.
- تحديد العدد الإجمالي للمعلمين، مع احتساب المعلم الأول ضمن العدد عند تفعيله.
- إنشاء بطاقات المعلمين تلقائيًا وفق العدد والمادة أو مواد القسم المختارة.
- في خطة المادة الواحدة يُثبت تخصص جميع المعلمين على المادة تلقائيًا.
- في القسم متعدد المواد لا تظهر للمعلمين إلا تخصصات المواد المختارة داخل القسم.
- إنشاء متطلبات الصفوف والحصص تلقائيًا بحسب نطاق المدرسة ونظام الدوام، مع بقاء الأعداد قابلة للتعديل.
- إدارة محلية خفيفة للخطط: حفظ الخطة الحالية، فتح خطة محفوظة، إنشاء خطة جديدة، وحذف النسخة المحفوظة دون المساس بالخطة المفتوحة.
- عند تغيير المادة أو القسم تُحفظ الخطة السابقة تلقائيًا قبل إنشاء الخطة الجديدة.
- ترحيل بيانات الإصدارات السابقة، ومنها خطة العلوم الحالية، دون فقد البيانات.

## الوظائف المحفوظة

- دعم الصفوف من الأول إلى الثاني عشر.
- مكتبة مواد المدارس الحكومية في سلطنة عُمان.
- تحكم مرن في نطاق إسناد كل معلم.
- توليد نماذج توزيع متعددة ومقارنتها.
- تثبيت المعلمين والشعب وإعادة توزيع الباقي.
- نقل الشعب مع فحص التخصص وسقف النصاب.
- حفظ المسودة واعتماد الخطة.
- تقرير PDF رسمي وExcel منسق بثلاث أوراق.
- تشغيل محلي داخل المتصفح دون Supabase أو Gemini في هذه المرحلة.

## الرفع إلى GitHub

1. ارفع الملفات المعدلة إلى جذر مستودع `qistas` مع الحفاظ على المسارات.
2. كل رفع إلى فرع `main` يشغّل الاختبارات ويبني الموقع وينشره تلقائيًا.
3. افتح تبويب `Actions` وانتظر نجاح `Test and deploy GitHub Pages`.
4. حدّث صفحة التطبيق عبر `Ctrl + F5`.

## الفحص

```bash
npm test
npm run build
```
