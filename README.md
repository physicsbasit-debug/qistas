# قِسطاس

تطبيق عربي RTL خفيف لتوزيع أنصبة المعلمين والشعب.

**أنصبة موزونة، توزيع أذكى.**

### جديد في 0.7.0

- قالب تقرير عربي RTL بمقاس A4 أفقي.
- رأس رسمي يحمل هوية قِسطاس وبيانات المدرسة والقسم والسنة الدراسية.
- جدول موحد للمعلمين مع تجميع الشعب المتتابعة بدل طباعة بطاقات الواجهة.
- ملخص لتغطية المقررات والحصص، وحقلان للتوقيع والاعتماد.
- منع ظهور أزرار النقل والتثبيت وأدوات التحرير داخل التقرير.


## الإصدار 0.7.0: التقرير الرسمي المنظم

- يعمل التطبيق كاملًا داخل المتصفح دون Supabase أو Gemini.
- يولّد 20 نموذجًا في الدفعة الأولى، وحتى 100 نموذج مختلف معروض.
- يسمح بفتح أي نموذج بوصفه خطة قابلة للتعديل.
- يمكن تثبيت توزيع معلم كامل حتى لا تتغير شعبه.
- يمكن نقل شعبة إلى معلم بديل مسموح له وبسعة كافية.
- تُثبّت الشعبة المنقولة تلقائيًا حتى لا يعيد المحرك إرجاعها.
- يعيد قِسطاس توزيع الجزء غير المثبت فقط، مع الحفاظ على قرارات المستخدم.
- يمكن اعتماد الخطة وحفظ المسودة تلقائيًا على الجهاز.
- يدعم تصدير الخطة الحالية إلى CSV وإنشاء تقرير PDF رسمي مستقل عن واجهة التحرير.

## الوظائف الحالية

- بيانات علوم تجريبية للصفوف 8 إلى 10.
- إضافة وتعديل وحذف المعلمين.
- إضافة الصفوف والمواد وعدد الشعب والحصص.
- تحكم بسيط في نطاق توزيع كل معلم.
- توليد نماذج متعددة مختلفة تحت القيود نفسها.
- ترتيب النماذج ومقارنتها والتنقل بينها.
- تثبيت المعلمين والشعب وإعادة توزيع الباقي.
- نقل الشعب مع فحص النطاق وسقف النصاب قبل التنفيذ.
- كشف الشعب التي يتعذر إسنادها.
- حفظ البيانات والخطة الحالية محليًا مع ترحيل بيانات الإصدارات السابقة.

## الرفع إلى GitHub

1. ارفع الملفات المعدلة إلى جذر مستودع `qistas` مع الحفاظ على المسارات.
2. كل رفع إلى فرع `main` يشغّل الاختبارات ويبني الموقع وينشره تلقائيًا.
3. افتح تبويب `Actions` وانتظر نجاح `Test and deploy GitHub Pages`.
4. حدّث صفحة التطبيق عبر `Ctrl + F5`.

## الفحص

```bash
npm test
npm run build
```

## الذكاء الاصطناعي

تكامل Gemini غير مفعّل في هذا الإصدار، ولا يوجد مشروع Supabase مرتبط بالتطبيق. سيُضاف لاحقًا كمرحلة مستقلة بعد استقرار تجربة التعديل والاعتماد عمليًا.
