# قِسطاس

تطبيق عربي RTL خفيف لتوزيع أنصبة المعلمين والشعب.

**أنصبة موزونة، توزيع أذكى.**

## الإصدار 0.3.0: التحكم المبسّط

أعيد تصميم شاشة المعلمين لتكون أسرع وأسهل:

- حذف الحد الأدنى والمستهدف والأعلى من كل بطاقة معلم.
- ضبط سقف عام واحد للمعلم وسقف عام للمعلم الأول.
- اختيار دور المعلم من قائمة بسيطة: معلم أو معلم أول.
- اختيار طريقة توزيع واحدة لكل معلم:
  - تخصصه في جميع الصفوف.
  - تخصصه في صف واحد.
  - صف ومادة فقط.
  - تخصصه مع صف ومادة إضافيين.
  - اختيار يدوي بمربعات تحديد.
- في الاختيار اليدوي: المحدد مسموح، وغير المحدد ممنوع.
- مواد مثل العلوم العامة لا تظهر بوصفها «خارج التخصص» إذا اختار المستخدم إسنادها للمعلم.
- عرض نتيجة واحدة مقترحة، مع وضع البدائل داخل قسم اختياري غير مزعج.

## الوظائف الحالية

- بيانات علوم تجريبية للصفوف 8 إلى 10.
- إضافة وتعديل وحذف المعلمين.
- إضافة الصفوف والمواد وعدد الشعب والحصص.
- محرك حتمي يحترم خيارات التدريس وسقف النصاب.
- كشف الشعب التي يتعذر إسنادها.
- حفظ البيانات محليًا مع ترحيل بيانات الإصدار السابق.
- تصدير CSV وطباعة النتيجة إلى PDF.
- مراجعة اختيارية عبر Gemini من خلال Supabase Edge Function، دون كشف مفتاح API في الواجهة.

## الرفع إلى GitHub

1. ارفع الملفات المعدلة إلى جذر مستودع `qistas` مع الحفاظ على المسارات.
2. كل رفع إلى فرع `main` يشغّل الاختبارات ويبني الموقع وينشره تلقائيًا.
3. افتح تبويب `Actions` وانتظر نجاح `Test and deploy GitHub Pages`.
4. حدّث صفحة التطبيق عبر `Ctrl + F5`.

## الفحص

```bash
npm test
npm run build
```

## ربط Gemini

1. أضف السر `GEMINI_API_KEY` في إعدادات Supabase Edge Functions.
2. انشر الوظيفة الموجودة في `supabase/functions/review-distribution`.
3. أدخل رابط Supabase ومفتاح `anon` داخل قسم مراجعة Gemini الاختيارية.

> لا تضع مفتاح Gemini داخل كود الواجهة أو مستودع GitHub العام. الإنترنت ليس خزنة، مهما ارتدى من أقفال صغيرة.
