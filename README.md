# قِسطاس

تطبيق عربي RTL خفيف لتوزيع أنصبة المعلمين والشعب.

**أنصبة موزونة، توزيع أذكى.**

## الإصدار 0.5.0: نماذج توزيع متعددة

- لا يكتفي التطبيق باقتراح واحد؛ يبحث عن حلول صحيحة ومتنوعة لنفس الإعدادات.
- يولّد 20 نموذجًا في الدفعة الأولى، ويمكن طلب دفعات إضافية حتى 100 نموذج معروض.
- يحذف النماذج المتطابقة تلقائيًا ويرتب البقية حسب التوازن، التخصص، وقلة التشعب.
- يعرض تصنيفات واضحة مثل: الأكثر توازنًا، الأكثر تخصصًا، والأقل تشعبًا.
- يتيح الانتقال بين النماذج من قائمة واحدة وأزرار السابق والتالي.
- يوفر مقارنة مختصرة لأفضل ثمانية نماذج دون ازدحام الواجهة.
- يحافظ في كل نموذج على نطاق تدريس المعلم وسقف النصاب وعدم فقد الحصص.
- ما زال محرك الإصلاح الشامل يعيد نقل التكليفات عند تجزؤ السعة.
- تراجع Gemini اختياريًا أفضل 12 نموذجًا فقط، ثم ترشح واحدًا من المعرفات الموجودة فعلًا.

## الوظائف الحالية

- بيانات علوم تجريبية للصفوف 8 إلى 10.
- إضافة وتعديل وحذف المعلمين.
- إضافة الصفوف والمواد وعدد الشعب والحصص.
- تحكم بسيط في نطاق توزيع كل معلم.
- توليد نماذج متعددة مختلفة تحت القيود نفسها.
- ترتيب النماذج ومقارنتها والتنقل بينها.
- كشف الشعب التي يتعذر إسنادها.
- حفظ البيانات محليًا مع ترحيل بيانات الإصدارات السابقة.
- تصدير النموذج المحدد إلى CSV وطباعته إلى PDF.
- مراجعة اختيارية عبر Gemini دون كشف مفتاح API في الواجهة.

## الرفع إلى GitHub

1. ارفع الملفات المعدلة إلى جذر مستودع `qistas` مع الحفاظ على المسارات.
2. كل رفع إلى فرع `main` يشغّل الاختبارات ويبني الموقع وينشره تلقائيًا.
3. افتح تبويب `Actions` وانتظر نجاح `Test and deploy GitHub Pages`.
4. حدّث صفحة التطبيق عبر `Ctrl + F5`.

## الفحص

```bash
npm test
npm run build
```

## ربط Gemini

1. أضف السر `GEMINI_API_KEY` في إعدادات Supabase Edge Functions.
2. انشر الوظيفة الموجودة في `supabase/functions/review-distribution`.
3. أدخل رابط Supabase ومفتاح `anon` داخل قسم مراجعة Gemini الاختيارية.

> لا تضع مفتاح Gemini داخل كود الواجهة أو مستودع GitHub العام. هذا ليس ذكاءً اصطناعيًا، بل تبرع مالي مفتوح للإنترنت.
