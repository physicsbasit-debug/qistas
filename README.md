# قِسطاس

## الإصدار 1.3.6: تبديل أرقام الشعب بين المعلمين

- يمكن اختيار شعبة من الخطة الحالية وتبديلها مع شعبة مماثلة لدى معلم آخر.
- يقتصر التبديل على الشعب التابعة للمادة والصف نفسيهما، مثل العاشر/2 مع العاشر/3 في الفيزياء.
- تنفذ العملية دفعة واحدة؛ فلا تتكرر شعبة ولا تضيع أخرى، ويبقى نصاب المعلمين كما هو.
- تُثبّت الشعبتان بعد التبديل، ويحافظ عليهما «إعادة توزيع غير المثبت» في موقعيهما الجديدين.
- لا يسمح التبديل إذا كان أحد المعلمين مثبتًا، ولا يغيّر قواعد التوزيع الآلي أو النقل المرن لعلوم الثامن.

## الإصدار 1.3.5: نقل علوم الثامن بين تخصصات العلوم

- يمكن نقل أي شعبة من «العلوم العامة · الصف الثامن» يدويًا بين معلمي الفيزياء والكيمياء والأحياء.
- يبقى النقل خاضعًا لنشاط المعلم، وسقف النصاب، وتثبيت المعلمين والشعب.
- تُثبّت الشعبة المنقولة تلقائيًا، ويحافظ عليها «إعادة توزيع غير المثبت» في موقعها الجديد.
- لا يغيّر الاستثناء ضوابط التوليد الآلي، ولا يسمح بنقل مقررات الصفين التاسع والعاشر بين تخصصات مختلفة.
- أضيفت اختبارات واجهة ومحرك تغطي النقل والتثبيت وإعادة التوزيع وحدود الاستثناء.

## الإصدار 1.3.4 Fix 1: توحيد حالة الخطة في PDF وExcel

- يعرض التقرير وExcel الآن «الخطة المعتمدة» عند اعتماد المسودة، بدل بقاء العبارة القديمة «الخطة قيد التعديل».
- تُرحّل المسودات المعتمدة المحفوظة سابقًا تلقائيًا إلى التسمية الصحيحة عند فتحها.
- عند تعديل خطة معتمدة تعود التسمية تلقائيًا إلى «الخطة قيد التعديل».

- توسيع عمود اسم المعلم لعرض أسماء طويلة مثل «عبدالعزيز اليحيائي» بوضوح.
- تقليل عرض عمود الشعب والمقررات المسندة دون التأثير في تجميع التكليفات.
- إبقاء أسماء المعلمين في سطر واحد داخل التقرير عند المساحة المعتادة.
- الحفاظ على A4 أفقي، والكثافة التلقائية، والتوقيعات والتذييل، ومحرك PDF المباشر.
- لا تغيير في محرك التوزيع أو Excel أو الاعتماد والحفظ.

تطبيق عربي RTL خفيف لتوزيع أنصبة المعلمين والشعب.

**أنصبة موزونة، توزيع أذكى.**

## الإصدار 1.3.3: تحسين قراءة التقرير واستغلال صفحة A4

- تكبير الخطوط وعناوين التقرير وجدول المعلمين بصورة متوازنة.
- توسيع عمود الشعب والمقررات وزيادة ارتفاع الصفوف عند الخطط الصغيرة والمتوسطة.
- اعتماد كثافة تلقائية للتقرير: واسعة للخطط الصغيرة، قياسية للمتوسطة، ومدمجة للخطط الكبيرة.
- دفع التوقيعات والتذييل إلى أسفل الصفحة واستغلال المساحة البيضاء دون تمديد مصطنع للمحتوى.
- الحفاظ على A4 أفقي مباشر، وتعدد الصفحات عند زيادة البيانات.

## الإصدار 1.3.2: تنزيل PDF مباشر

- ينشئ قِسطاس ملف PDF حقيقيًا مباشرة من التطبيق بمقاس A4 أفقي.
- لا يعتمد على نافذة الطباعة أو Microsoft Print to PDF.
- يحافظ على RTL والألوان والهوية البصرية، وينزل الملف بزر واحد.
- يبقى تقرير HTML الداخلي أساس التصميم، بينما تُحوّل صفحاته محليًا إلى PDF دون إرسال البيانات إلى خدمة خارجية.


## الإصدار 1.3.1 Fix 1: فحص الجاهزية قبل التوزيع

- إضافة فحص فوري للحصص المطلوبة مقابل الطاقة القصوى للمعلمين قبل تشغيل محرك البحث.
- إيقاف التوليد مباشرة عند وجود عجز واضح، مع بيان مقدار العجز وعدد الشعب غير القابلة للتغطية والحد الأدنى للمعلمين الإضافيين.
- فحص قيود الإسناد حسب الصف والمادة، واكتشاف الحالات التي لا يوجد فيها معلم مسموح له بالتغطية حتى لو كانت الطاقة الإجمالية كافية.
- إضافة فحص مجمّع للقيود المشتركة بين المعلمين لمنع البحث الطويل في خطة مستحيلة بسبب نطاقات الإسناد.
- إضافة معاينة توزيع جزئي سريعة للتشخيص فقط، مع منع اعتمادها أو تصديرها إلى Excel أو PDF.
- إغلاق اختبار التحكم المرن رسميًا لمعلمي العلوم: صف محدد من التخصص، علوم الثامن فقط، علوم الثامن مع تخصص محدد، والتخصص في جميع الصفوف.
- الحفاظ على محرك النماذج والتثبيت والنقل وإعادة توزيع غير المثبت والتقارير دون تغيير في السلوك الطبيعي للخطط القابلة للتغطية.

## الإصدار 1.3.0: تثبيت التعميم واختبارات القبول

- تحسين عبارات الواجهة الافتتاحية لتوضيح مسار العمل والنتيجة بلغة مهنية مباشرة.
- استبدال وصف «الحصص المطلوبة» بـ«إجمالي الحصص الأسبوعية» ووصف عدد الشعب بـ«التكليفات التدريسية» لزيادة الدقة.
- إضافة اختبارات قبول لمادة واحدة عبر نطاقات صفية مختلفة، وقسم العلوم متعدد المواد، وعزل مخرجات PDF وExcel حسب الخطة الحالية.
- التحقق من أن النموذج الأول يكتمل دون شعب غير مسندة أو تجاوز للنصاب في حالات التربية الإسلامية، واللغة العربية، والرياضيات، واللغة الإنجليزية، والعلوم.
- عدم إضافة Supabase أو Gemini أو تغيير منطق التثبيت والنقل والتصدير.

## الإصدار 1.2.2: اسم تلقائي ونموذج واحد عند الطلب

- إنشاء اسم الخطة تلقائيًا بصيغة `توزيع أنصبة مادة [اسم المادة]` أو `توزيع أنصبة قسم [اسم القسم]`.
- حذف حقل اسم الخطة من الواجهة ومنع اختلافه عن المادة أو القسم المحدد.
- حذف خيار فترة واحدة/فترتين من الواجهة؛ لأن توزيع الأنصبة يعتمد على عدد الشعب والحصص المدخلة فعليًا.
- عرض أفضل توزيع أولًا بدل توليد مجموعة كبيرة مسبقًا.
- زر `نموذج بديل` يولّد نموذجًا مختلفًا واحدًا في كل ضغطة ويحفظ البدائل السابقة.
- منع تكرار النموذج نفسه مع إبقاء السابق/التالي والمقارنة والاعتماد.
- خفض البحث الأولي إلى ثماني محاولات فقط، والبحث عن البديل عند الطلب دون تجميد الواجهة طويلًا.

## الإصدار 1.2.1: تبسيط التهيئة وتسريع التوليد

- حذف التصنيفات الوصفية من قائمة المواد وعرض أسماء المواد فقط.
- استبدال بطاقات نوع الخطة الكبيرة باختيار مضغوط وواضح.
- توحيد التهيئة في زر واحد يطبق المادة والشعب وعدد المعلمين معًا.
- إعادة تسمية البطاقات التلقائية بحسب المادة المختارة ومنع بقاء أسماء مادة سابقة.
- إخفاء نسخ إعداد الإسناد في خطة المادة الواحدة، وإظهاره فقط عند فائدته في الأقسام متعددة المواد.
- توليد أول مجموعة من النماذج بسرعة، مع إبقاء البحث الموسع عبر زر النماذج الإضافية.

## الإصدار 1.2.0: إعداد موحّد وخطة معزولة لكل مادة أو قسم

- دمج بيانات المدرسة، نطاق الصفوف، المادة أو القسم، عدد المعلمين، الشعب والحصص داخل خطوة واحدة منظمة.
- اختيار نوع الخطة:
  - مادة واحدة، مثل اللغة العربية أو الرياضيات أو الفيزياء.
  - قسم متعدد المواد، مثل العلوم أو الدراسات الاجتماعية.
- منع دخول أي مادة من خارج نطاق الخطة إلى المعلمين أو التوزيع أو Excel أو تقرير PDF.
- تحديد العدد الإجمالي للمعلمين، مع احتساب المعلم الأول ضمن العدد عند تفعيله.
- إنشاء بطاقات المعلمين تلقائيًا وفق العدد والمادة أو مواد القسم المختارة.
- في خطة المادة الواحدة يُثبت تخصص جميع المعلمين على المادة تلقائيًا.
- في القسم متعدد المواد لا تظهر للمعلمين إلا تخصصات المواد المختارة داخل القسم.
- إنشاء متطلبات الصفوف والحصص تلقائيًا بحسب نطاق المدرسة، مع بقاء الأعداد قابلة للتعديل.
- إدارة محلية خفيفة للخطط: حفظ الخطة الحالية، فتح خطة محفوظة، إنشاء خطة جديدة، وحذف النسخة المحفوظة دون المساس بالخطة المفتوحة.
- عند تغيير المادة أو القسم تُحفظ الخطة السابقة تلقائيًا قبل إنشاء الخطة الجديدة.
- ترحيل بيانات الإصدارات السابقة، ومنها خطة العلوم الحالية، دون فقد البيانات.

## الرفع إلى GitHub

1. ارفع الملفات المعدلة إلى جذر مستودع `qistas` مع الحفاظ على المسارات.
2. كل رفع إلى فرع `main` يشغّل الاختبارات ويبني الموقع وينشره تلقائيًا.
3. افتح تبويب `Actions` وانتظر نجاح `Test and deploy GitHub Pages`.
4. حدّث صفحة التطبيق عبر `Ctrl + F5`.
