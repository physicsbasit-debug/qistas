# قِسطاس

تطبيق عربي RTL خفيف لتوزيع أنصبة المعلمين والشعب.

**أنصبة موزونة، توزيع أذكى.**

## الإصدار 0.5.1: محرك محلي مستقر

- يعمل التطبيق كاملًا داخل المتصفح دون Supabase أو Gemini.
- لا يحتاج تسجيل دخول أو مفتاح API أو إعدادات اتصال.
- يحتفظ بتعدد نماذج التوزيع: 20 نموذجًا في الدفعة الأولى، وحتى 100 نموذج معروض.
- يحذف النماذج المتطابقة ويرتب الحلول حسب التوازن، التخصص، وقلة التشعب.
- يحافظ على نطاق تدريس كل معلم وسقف النصاب وعدم فقد الحصص.
- يخزن البيانات محليًا في المتصفح، مع إمكانية التصدير إلى CSV والطباعة إلى PDF.

## الوظائف الحالية

- بيانات علوم تجريبية للصفوف 8 إلى 10.
- إضافة وتعديل وحذف المعلمين.
- إضافة الصفوف والمواد وعدد الشعب والحصص.
- تحكم بسيط في نطاق توزيع كل معلم.
- توليد نماذج متعددة مختلفة تحت القيود نفسها.
- ترتيب النماذج ومقارنتها والتنقل بينها.
- كشف الشعب التي يتعذر إسنادها.
- حفظ البيانات محليًا مع ترحيل بيانات الإصدارات السابقة.
- تصدير النموذج المحدد إلى CSV وطباعته إلى PDF.

## الرفع إلى GitHub

1. ارفع الملفات المعدلة إلى جذر مستودع `qistas` مع الحفاظ على المسارات.
2. كل رفع إلى فرع `main` يشغّل الاختبارات ويبني الموقع وينشره تلقائيًا.
3. افتح تبويب `Actions` وانتظر نجاح `Test and deploy GitHub Pages`.
4. حدّث صفحة التطبيق عبر `Ctrl + F5`.

## الفحص

```bash
npm test
npm run build
```

## الذكاء الاصطناعي

تكامل Gemini غير مفعّل في هذا الإصدار، ولا يوجد مشروع Supabase مرتبط بالتطبيق. سيُضاف لاحقًا كمرحلة مستقلة بعد استقرار محرك التوزيع وتجربة النماذج فعليًا.
