# قِسطاس

تطبيق عربي RTL خفيف لتوزيع أنصبة المعلمين والشعب.

**أنصبة موزونة، توزيع أذكى.**

## الإصدار 1.3.0: تثبيت التعميم واختبارات القبول

- تحسين عبارات الواجهة الافتتاحية لتوضيح مسار العمل والنتيجة بلغة مهنية مباشرة.
- استبدال وصف «الحصص المطلوبة» بـ«إجمالي الحصص الأسبوعية» ووصف عدد الشعب بـ«التكليفات التدريسية» لزيادة الدقة.
- إضافة اختبارات قبول لمادة واحدة عبر نطاقات صفية مختلفة، وقسم العلوم متعدد المواد، وعزل مخرجات PDF وExcel حسب الخطة الحالية.
- التحقق من أن النموذج الأول يكتمل دون شعب غير مسندة أو تجاوز للنصاب في حالات التربية الإسلامية، واللغة العربية، والرياضيات، واللغة الإنجليزية، والعلوم.
- عدم إضافة Supabase أو Gemini أو تغيير منطق التثبيت والنقل والتصدير.

## الإصدار 1.2.2: اسم تلقائي ونموذج واحد عند الطلب

- إنشاء اسم الخطة تلقائيًا بصيغة `توزيع أنصبة مادة [اسم المادة]` أو `توزيع أنصبة قسم [اسم القسم]`.
- حذف حقل اسم الخطة من الواجهة ومنع اختلافه عن المادة أو القسم المحدد.
- حذف خيار فترة واحدة/فترتين من الواجهة؛ لأن توزيع الأنصبة يعتمد على عدد الشعب والحصص المدخلة فعليًا.
- عرض أفضل توزيع أولًا بدل توليد مجموعة كبيرة مسبقًا.
- زر `نموذج بديل` يولّد نموذجًا مختلفًا واحدًا في كل ضغطة ويحفظ البدائل السابقة.
- منع تكرار النموذج نفسه مع إبقاء السابق/التالي والمقارنة والاعتماد.
- خفض البحث الأولي إلى ثماني محاولات فقط، والبحث عن البديل عند الطلب دون تجميد الواجهة طويلًا.

## الإصدار 1.2.1: تبسيط التهيئة وتسريع التوليد

- حذف التصنيفات الوصفية من قائمة المواد وعرض أسماء المواد فقط.
- استبدال بطاقات نوع الخطة الكبيرة باختيار مضغوط وواضح.
- توحيد التهيئة في زر واحد يطبق المادة والشعب وعدد المعلمين معًا.
- إعادة تسمية البطاقات التلقائية بحسب المادة المختارة ومنع بقاء أسماء مادة سابقة.
- إخفاء نسخ إعداد الإسناد في خطة المادة الواحدة، وإظهاره فقط عند فائدته في الأقسام متعددة المواد.
- توليد أول مجموعة من النماذج بسرعة، مع إبقاء البحث الموسع عبر زر النماذج الإضافية.

## الإصدار 1.2.0: إعداد موحّد وخطة معزولة لكل مادة أو قسم

- دمج بيانات المدرسة، نطاق الصفوف، المادة أو القسم، عدد المعلمين، الشعب والحصص داخل خطوة واحدة منظمة.
- اختيار نوع الخطة:
  - مادة واحدة، مثل اللغة العربية أو الرياضيات أو الفيزياء.
  - قسم متعدد المواد، مثل العلوم أو الدراسات الاجتماعية.
- منع دخول أي مادة من خارج نطاق الخطة إلى المعلمين أو التوزيع أو Excel أو تقرير PDF.
- تحديد العدد الإجمالي للمعلمين، مع احتساب المعلم الأول ضمن العدد عند تفعيله.
- إنشاء بطاقات المعلمين تلقائيًا وفق العدد والمادة أو مواد القسم المختارة.
- في خطة المادة الواحدة يُثبت تخصص جميع المعلمين على المادة تلقائيًا.
- في القسم متعدد المواد لا تظهر للمعلمين إلا تخصصات المواد المختارة داخل القسم.
- إنشاء متطلبات الصفوف والحصص تلقائيًا بحسب نطاق المدرسة، مع بقاء الأعداد قابلة للتعديل.
- إدارة محلية خفيفة للخطط: حفظ الخطة الحالية، فتح خطة محفوظة، إنشاء خطة جديدة، وحذف النسخة المحفوظة دون المساس بالخطة المفتوحة.
- عند تغيير المادة أو القسم تُحفظ الخطة السابقة تلقائيًا قبل إنشاء الخطة الجديدة.
- ترحيل بيانات الإصدارات السابقة، ومنها خطة العلوم الحالية، دون فقد البيانات.

## الوظائف المحفوظة

- دعم الصفوف من الأول إلى الثاني عشر.
- مكتبة مواد المدارس الحكومية في سلطنة عُمان.
- تحكم مرن في نطاق إسناد كل معلم.
- إنشاء أفضل توزيع أولًا، ثم توليد بدائل مختلفة عند الطلب ومقارنتها.
- تثبيت المعلمين والشعب وإعادة توزيع الباقي.
- نقل الشعب مع فحص التخصص وسقف النصاب.
- حفظ المسودة واعتماد الخطة.
- تقرير PDF رسمي وExcel منسق بثلاث أوراق.
- تشغيل محلي داخل المتصفح دون Supabase أو Gemini في هذه المرحلة.

## الرفع إلى GitHub

1. ارفع الملفات المعدلة إلى جذر مستودع `qistas` مع الحفاظ على المسارات.
2. كل رفع إلى فرع `main` يشغّل الاختبارات ويبني الموقع وينشره تلقائيًا.
3. افتح تبويب `Actions` وانتظر نجاح `Test and deploy GitHub Pages`.
4. حدّث صفحة التطبيق عبر `Ctrl + F5`.

## الفحص
