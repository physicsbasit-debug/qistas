# قِسطاس

تطبيق عربي RTL خفيف لتوزيع أنصبة المعلمين والشعب.

**أنصبة موزونة، توزيع أذكى.**

## الإصدار 1.1.0: مكتبة مواد المدارس الحكومية في سلطنة عُمان

- مكتبة مواد منظمة للصفوف من الأول إلى الثاني عشر.
- تشمل المواد الأساسية والمصاحبة والاختيارية، إضافة إلى مواد المسار المهني والتقني.
- قوالب جاهزة للأقسام: التربية الإسلامية، العربية، الإنجليزية، الرياضيات، العلوم، الدراسات الاجتماعية، تقنية المعلومات، المهارات، الرياضة، الفنون، الموسيقى، التوجيه المهني، اللغات والمواد الاختيارية، والمسارات المهنية.
- ترشيح المواد تلقائيًا بحسب الصف المختار.
- اقتراح عدد الحصص وفق نظام المدرسة: فترة واحدة أو فترتان، مع بقاء الأرقام قابلة للتعديل.
- إضافة مواد القسم لجميع صفوف نطاق المدرسة بنقرة واحدة، دون تكرار المواد الموجودة.
- إمكانية كتابة أي مادة مخصصة غير موجودة في المكتبة.
- قائمة اقتراحات لتخصصات المعلمين بدل حصر التطبيق في مواد العلوم.

> الحصص الافتراضية إرشادية وقابلة للتعديل، لأن خطط المدرسة والمواد الاختيارية والمسارات الخاصة قد تختلف.

## الوظائف الحالية

- مثال علوم جاهز للصفوف 8 إلى 10، مع إمكانية بناء خطة لأي مادة وصفوف من 1 إلى 12.
- إضافة وتعديل وحذف المعلمين.
- إضافة الصفوف والمواد وعدد الشعب والحصص.
- تحكم بسيط في نطاق توزيع كل معلم.
- توليد نماذج متعددة مختلفة تحت القيود نفسها.
- ترتيب النماذج ومقارنتها والتنقل بينها.
- تثبيت المعلمين والشعب وإعادة توزيع الباقي.
- نقل الشعب مع فحص النطاق وسقف النصاب قبل التنفيذ.
- كشف الشعب التي يتعذر إسنادها.
- حفظ البيانات والخطة الحالية محليًا مع ترحيل بيانات الإصدارات السابقة.
- اعتماد الخطة وإنشاء تقرير PDF رسمي مستقل عن واجهة التحرير.
- تصدير Excel منسق بثلاث أوراق عمل.

## الرفع إلى GitHub

1. ارفع الملفات المعدلة إلى جذر مستودع `qistas` مع الحفاظ على المسارات.
2. كل رفع إلى فرع `main` يشغّل الاختبارات ويبني الموقع وينشره تلقائيًا.
3. افتح تبويب `Actions` وانتظر نجاح `Test and deploy GitHub Pages`.
4. حدّث صفحة التطبيق عبر `Ctrl + F5`.

## الفحص

```bash
npm test
npm run build
```

## الذكاء الاصطناعي

تكامل Gemini غير مفعّل في هذا الإصدار، ولا يوجد مشروع Supabase مرتبط بالتطبيق. سيُضاف لاحقًا كمرحلة مستقلة بعد استقرار تجربة التعديل والاعتماد عمليًا.
